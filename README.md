# Breeze Growth Audit

**Live → https://eddieatadapty.github.io/breeze-flow-rebuild/**

Five ideas to turn more Breeze users into subscribers, each built into a clickable version of Breeze's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Give people back the tests they liked | +10–20% CR to trial |
| 02 | Clear the road to the paywall | +10–15% CR to trial |
| 03 | Proof where people decide | +10–15% CR to trial |
| 04 | Ask for the account once there’s something to save | +5–10% CR to trial |
| 05 | One honest offer for people who tap Skip | +5–10% ARPU |

Every price, rating and feature comes from Breeze's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Breeze. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
